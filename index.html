About FunStudio

FunStudio is a specialized online IDE for WCH CH32 RISC-V microcontrollers and the ch32fun SDK.

100% Client-Side: Real GNU GCC 15.2.0 and GNU Binutils 2.44 run directly inside browser WebAssembly with zero server dependency.

Shortcuts:
  • Ctrl + Enter: Compile Firmware
  • Ctrl + S: Save Project
